## 1. Introducción

El presente manual tiene como finalidad orientar a los usuarios en el manejo del Sistema de Gestión de Biblioteca Universitaria. La aplicación busca facilitar la administración de materiales bibliográficos, usuarios, préstamos y demás actividades relacionadas con el funcionamiento de la biblioteca.

## 2. Objetivo del manual

Proporcionar una guía sencilla que permita conocer las diferentes pantallas del sistema y comprender su funcionamiento previsto.

## 3. Inicio de sesión

Al ingresar al sistema se presenta una ventana de bienvenida donde el usuario debe introducir sus credenciales.

1. Escribir el nombre de usuario.
2. Introducir la contraseña.
3. Presionar el botón Iniciar sesión.
4. Acceder al menú principal según los permisos asignados.

## 4. Resumen general

La pantalla principal presenta información relacionada con:

- Libros registrados.
- Préstamos activos.
- Usuarios registrados.
- Multas pendientes.
- Préstamos recientes.

Esta sección permite visualizar de manera rápida la actividad de la biblioteca.

## 5. Catálogo bibliográfico

Para acceder al catálogo, se debe seleccionar la opción Catálogo ubicada en el menú lateral.

La pantalla permite visualizar información como:

- ISBN.
- Título.
- Autor.
- Tipo de material.
- Stock.
- Ubicación.

El botón Nuevo registro está destinado a incorporar materiales bibliográficos.

## 6. Gestión de usuarios

En el apartado Usuarios se presenta el directorio de las personas registradas en el sistema.

La información mostrada incluye:

- Carné o identificación.
- Nombre completo.
- Tipo de usuario.
- Correo electrónico.
- Estado.

El botón Nuevo registro está destinado al ingreso de nuevos usuarios.

## 7. Préstamos y devoluciones

La sección Préstamos permite consultar los registros relacionados con la circulación de materiales bibliográficos.

Se muestra el número de préstamo, usuario, material, fecha, vencimiento y estado.

Para registrar un préstamo, el procedimiento previsto consiste en seleccionar Nuevo préstamo, identificar al usuario y el material, verificar la disponibilidad y confirmar la operación.

Las devoluciones y renovaciones deben respetar las reglas establecidas por la biblioteca.

## 8. Multas

El módulo de multas está destinado al control de los atrasos en las devoluciones.

Según los requisitos del proyecto, la multa corresponde a 50 colones por cada día de atraso, con un máximo de 2000 colones.

Los usuarios con multas pendientes no podrán realizar nuevos préstamos.

## 9. Reportes

El sistema contempla la generación de los siguientes reportes:

- Diez libros más prestados.
- Usuarios con multas pendientes.
- Materiales con stock crítico.
- Préstamos vencidos.

Se contempla la exportación de reportes a PDF y Excel.

## 10. Respaldo XML

Para acceder a esta sección se selecciona Respaldo XML en el menú lateral.

La interfaz presenta las siguientes opciones:

- Exportar catálogo XML.
- Exportar usuarios XML.
- Seleccionar archivo para importar.

Estas opciones están destinadas a facilitar el respaldo y la recuperación de información.

## 11. Configuración

Este módulo contempla la modificación del idioma, tema visual, parámetros del sistema y conexión con la base de datos.

## 12. Auditoría

La sección Auditoría permite visualizar el historial de acciones realizadas dentro del sistema.

La información presentada incluye:

- Usuario.
- Acción realizada.
- Módulo.
- Fecha y hora.

## 13. Cierre de sesión

Para finalizar el uso del sistema se debe seleccionar la opción Cerrar sesión, ubicada en la parte inferior del menú lateral.

## 14. Recomendaciones

- Mantener las credenciales de acceso protegidas.
- Verificar la información antes de registrar un préstamo.
- Realizar respaldos periódicamente.
- Mantener actualizado el catálogo bibliográfico.
- Reportar cualquier inconveniente al administrador.

## 15. Estado del manual

Este manual se elaboró a partir de las interfaces disponibles y los requisitos establecidos para el proyecto. Los procedimientos deberán validarse con la versión funcional del sistema.

## 16. Conclusión

El Sistema de Gestión de Biblioteca Universitaria busca simplificar las actividades administrativas de la biblioteca mediante una interfaz organizada que facilite el acceso a la información y el control de sus operaciones.
